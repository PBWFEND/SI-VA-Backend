## Struktur Materi yang Dibahas

### 1. Judul
Bedah Web Desain Rest Api Studi Kasus Youtube

### 2. Tujuan
Mengidentifikasi interaksi pengguna pada aplikasi YouTube, menganalisis HTTP Method, endpoint, data request dan response, serta merancang API berdasarkan prinsip REST.

### 3. Bedah Kasus YouTube
Menganalisis penggunaan YouTube sebagai studi kasus dan mengidentifikasi berbagai proses atau interaksi yang dilakukan pengguna dengan sistem, seperti mencari video, melihat detail video, melihat komentar, menambahkan komentar, membuat playlist, dan menambahkan video ke playlist.

### 4. Analisis Interaksi YouTube
Menganalisis contoh interaksi pengguna dengan sistem, mulai dari request yang dikirim oleh client hingga response yang diterima dari REST API..

### 5. Pemetaan HTTP Method
Memetakan penggunaan HTTP Method seperti GET, POST, PATCH, dan DELETE berdasarkan kebutuhan operasi pada sistem YouTube.

### 6. Struktur Endpoint
Membahas struktur endpoint REST API yang digunakan untuk merepresentasikan resource seperti video, komentar, playlist, dan playlist item.

### 7. Request & Response
Membahas proses pengiriman request dari client ke REST API serta response yang diterima kembali dalam bentuk data JSON.

### 8. HTTP Status Code
Membahas penggunaan HTTP Status Code seperti 200 OK, 201 Created, 204 No Content, 400 Bad Request, 404 Not Found, dan 500 Internal Server Error sesuai dengan kondisi response.

### 9. Prinsip RESTful
Membahas penerapan prinsip RESTful dalam perancangan API YouTube, yaitu penggunaan resource pada endpoint dan HTTP Method untuk menentukan operasi seperti mengambil, membuat, mengubah, dan menghapus data

### 10. Kesimpulan
Merangkum hasil analisis dan pemahaman kelompok mengenai konsep REST API melalui studi kasus YouTube, mulai dari interaksi pengguna, HTTP Method, endpoint, request dan response, hingga HTTP Status Code dan prinsip RESTful.
