# Refleksi Tugas 1 Pertemuan 2

Dalam pengerjaan Tugas 1 mengenai refactor dan mini-service, saya mempelajari beberapa fitur JavaScript modern yang membantu membuat kode menjadi lebih terstruktur dan mudah dipahami.

Fitur pertama yang cukup membantu adalah **arrow function**. Penggunaan arrow function membuat deklarasi fungsi menjadi lebih sederhana dibandingkan penulisan fungsi dengan cara biasa. Hal ini membuat kode terlihat lebih ringkas dan lebih mudah dibaca.

Selanjutnya, saya menggunakan **destructuring dan template literal** untuk mempermudah pengolahan data. Destructuring dapat digunakan untuk mengambil nilai tertentu dari sebuah object secara langsung, sedangkan template literal memudahkan proses penyusunan teks yang berisi data atau variabel.

Fitur lain yang saya pelajari adalah **Promise dan async/await**. Dari penerapan pada mini-service, saya menjadi lebih memahami bahwa beberapa proses membutuhkan waktu sebelum menghasilkan data. Konsep ini saya terapkan pada fungsi `findAll`, `findById`, `create`, `update`, dan `delete` dengan memberikan simulasi delay pada setiap proses.

Bagian yang masih perlu saya pahami lebih lanjut adalah penggunaan **Promise.all()**. Saya masih perlu berlatih untuk membedakan kondisi ketika beberapa proses asynchronous dapat dijalankan secara bersamaan dengan kondisi ketika proses harus dilakukan secara berurutan. Dengan latihan lebih lanjut, saya berharap dapat menentukan penggunaan `Promise.all()` dengan lebih tepat.
