# Refleksi Tugas 1 — Absensi Organisasi

## 1. Tiga fitur P2 yang paling mengubah cara saya menulis kode

### 1. Async/Await dan Promise
Fitur async/await membuat penulisan kode asynchronous menjadi lebih mudah dibaca. Pada tugas ini, async/await digunakan pada service absensi untuk mensimulasikan proses pengambilan data yang membutuhkan waktu.

### 2. Destructuring dan Default Value
Destructuring memudahkan saya mengambil data tertentu dari object tanpa harus menuliskan nama object berulang kali. Default value juga membantu memberikan nilai awal ketika data tidak diberikan.

### 3. Array Methods
Method seperti map(), filter(), find(), findIndex(), dan reduce() membuat pengolahan data menjadi lebih sederhana. Pada tugas ini, filter() digunakan untuk menghitung jumlah anggota yang hadir dan find() digunakan untuk mencari data absensi berdasarkan ID.

## 2. Hal yang Masih Membingungkan

Hal yang masih membingungkan bagi saya adalah memahami penggunaan Promise.all() dan bagaimana beberapa proses asynchronous dapat berjalan secara bersamaan. Saya masih perlu berlatih agar lebih memahami perbedaan proses asynchronous yang dijalankan secara berurutan dan secara paralel.
