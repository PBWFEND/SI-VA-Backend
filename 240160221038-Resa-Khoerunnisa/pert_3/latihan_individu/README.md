# Tugas 2 — Project Node.js dan HTTP Server Sederhana

## Deskripsi

Project ini merupakan tugas Node.js tanpa menggunakan Express.js.
Project menggunakan module bawaan Node.js untuk membuat HTTP Server,
konfigurasi aplikasi, response JSON, serta operasi file asynchronous.

## Teknologi

- Node.js
- JavaScript ES Module (ESM)
- node:http
- node:fs/promises
