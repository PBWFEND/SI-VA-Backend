# Refleksi Tugas 2 — Node.js dan HTTP Server Sederhana

Dalam pengerjaan tugas ini, saya belajar membangun HTTP server secara manual menggunakan Node.js murni tanpa Express.js. Poin penting yang dipelajari meliputi:
1. Menerapkan modularisasi menggunakan ESM (`import/export`).
2. Melakukan operasi baca file asynchronous dengan aman menggunakan `node:fs/promises`.
3. Mengelola konfigurasi aplikasi berbasis environment variable.
4. Menangani routing secara manual serta memberikan respons status 404 untuk endpoint yang tidak tersedia.
