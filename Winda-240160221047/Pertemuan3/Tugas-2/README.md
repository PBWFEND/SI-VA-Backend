# Tugas 2 — API Sederhana (Node.js)

Project ini dibuat untuk memenuhi tugas praktikum Backend Development tanpa menggunakan framework Express.js.

## Struktur File
- `config.js` : Modul konfigurasi aplikasi.
- `data/mahasiswa.json` : Sumber data mahasiswa berformat JSON.
- `server.js` : Berkas utama HTTP Server dan routing.
- `refleksi.md` : Catatan refleksi pengerjaan.

## Cara Menjalankan Server
Jalankan perintah berikut di terminal PowerShell:
```powershell
$env:COURSE_CODE="CPMK115"; node server.js
