## Struktur Materi yang Dibahas

### 1. Judul

Pengenalan topik aktivitas kelompok dan studi kasus yang digunakan, yaitu REST API dengan studi kasus Shopee.

### 2. Tujuan

Menjelaskan tujuan analisis terhadap aplikasi Shopee dari sudut pandang komunikasi client-server dan REST API, termasuk mengidentifikasi interaksi pengguna, HTTP Method, endpoint, request body, dan status code.

### 3. Bedah Kasus Shopee

Menganalisis beberapa interaksi pengguna pada aplikasi Shopee, seperti login, mencari produk, melihat detail produk, menambahkan produk ke keranjang, melakukan checkout, dan melihat pesanan.

### 4. Analisis Interaksi Shopee

Menganalisis proses interaksi pengguna dengan sistem melalui request dan response serta memperkirakan method dan endpoint yang digunakan pada setiap proses.

### 5. Pemetaan HTTP Method

Memetakan penggunaan HTTP Method seperti GET, POST, PATCH, dan DELETE berdasarkan kebutuhan operasi pada sistem.

### 6. Struktur Endpoint

Membahas struktur endpoint REST API Shopee yang menggunakan resource sebagai bagian utama URL, seperti `/api/products/{id}`, serta menjelaskan fungsi setiap bagian endpoint.

### 7. Request & Response

Membahas alur komunikasi antara pengguna, client, REST API, dan database, serta contoh request untuk mengambil data produk dan response dalam format JSON.

### 8. HTTP Status Code

Membahas penggunaan HTTP Status Code seperti 200 OK, 201 Created, 204 No Content, 400 Bad Request, 404 Not Found, dan 500 Internal Server Error sesuai dengan kondisi response.

### 9. Prinsip RESTful

Membahas penerapan prinsip RESTful pada rancangan API Shopee dengan penggunaan resource dan HTTP Method yang sesuai. Contohnya penggunaan `GET /api/products` dibandingkan endpoint seperti `POST /api/getProducts`.

### 10. Kesimpulan

Merangkum hasil analisis dan pemahaman kelompok mengenai konsep REST API melalui studi kasus Shopee, mulai dari interaksi pengguna, HTTP Method, endpoint, request dan response, hingga penerapan prinsip RESTful.
