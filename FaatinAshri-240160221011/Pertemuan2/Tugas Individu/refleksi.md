# Refleksi Pertemuan 2

Pada Pertemuan 2, saya mempelajari beberapa fitur JavaScript yang
berguna untuk backend.

## 1. Async/Await dan Promise: 
Saya jadi lebih memahami proses asynchronous. Async/await membuat kode
lebih mudah dibaca, sedangkan Promise.all() dapat menjalankan beberapa
proses secara paralel.

## 2. Array Method

Saya belajar menggunakan map, filter, dan reduce untuk mengolah data
array. Dibandingkan perulangan for, cara ini membuat kode lebih singkat
dan mudah dibaca.

## 3. Destructuring dan Template Literal

Destructuring memudahkan mengambil data dari object, sedangkan template
literal membuat pembuatan string dengan variabel menjadi lebih praktis.

## Hal yang Masih Membingungkan

Saya masih perlu latihan untuk menentukan kapan menggunakan Promise,
async/await, atau Promise.all() pada kasus asynchronous yang berbeda.
