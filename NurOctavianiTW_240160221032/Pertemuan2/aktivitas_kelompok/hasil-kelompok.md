# Hasil Kelompok — Pertemuan 3

# Tujuan
Melakukan pengujian API menggunakan Postman untuk memastikan endpoint dapat berjalan dengan baik.
# Pengujian API
a. GET /
- Method: GET
- URL: http://localhost:3003/
- Tujuan: Memeriksa informasi aplikasi.
- Hasil yang diharapkan: Menampilkan informasi nama aplikasi dan konfigurasi.
b. GET /health
- Method: GET
- URL: http://localhost:3003/health
- Tujuan: Memeriksa status server.
- Hasil yang diharapkan: Menampilkan status bahwa server berjalan.
# Kesimpulan
Pengujian dilakukan menggunakan Postman dengan metode GET. Hasil pengujian digunakan untuk mengetahui apakah setiap endpoint dapat diakses dan memberikan respons sesuai dengan fungsinya.
