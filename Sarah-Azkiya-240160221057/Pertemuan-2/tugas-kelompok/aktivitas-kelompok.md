## Struktur Materi yang Dibahas

### 1. Judul
Pengenalan topik aktivitas kelompok dan studi kasus yang digunakan.

### 2. Tujuan
Menjelaskan tujuan analisis terhadap aplikasi TokoPedia dari sudut pandang komunikasi client-server dan REST API.

### 3. Bedah Kasus TokoPedia
Menganalisis penggunaan Canva sebagai studi kasus dan mengidentifikasi proses atau interaksi yang terjadi antara pengguna dengan sistem.

### 4. Analisis Interaksi TokoPedia
Menganalisis contoh interaksi pengguna dengan sistem, mulai dari request yang dikirim hingga response yang diterima.

### 5. Pemetaan HTTP Method
Memetakan penggunaan HTTP Method seperti GET, POST, PUT/PATCH, dan DELETE berdasarkan kebutuhan operasi pada sistem.

### 6. Struktur Endpoint
Membahas struktur endpoint yang digunakan untuk merepresentasikan resource dan operasi dalam API.

### 7. Request & Response
Membahas struktur data yang dikirim melalui request serta data yang diterima melalui response dalam format JSON.

### 8. HTTP Status Code
Membahas penggunaan HTTP Status Code seperti 200, 201, 204, 400, 404, dan 500 sesuai dengan kondisi response.

### 9. Prinsip RESTful
Membahas penerapan prinsip RESTful dalam perancangan API, termasuk penggunaan resource, endpoint, HTTP Method, dan status code yang sesuai.

### 10. Kesimpulan
Merangkum hasil analisis dan pemahaman kelompok mengenai konsep REST API melalui studi kasus Tokopedia.
